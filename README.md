# Reel Life Vacation Rentals — Website Redesign

A modern website redesign concept for **Reel Life Vacation Rentals**, inspired by the Lake Palo Pinto experience in North Texas.

Designed and developed by **GlitterNGeek**, this concept reimagines how vacation rentals can be presented online—moving beyond property listings to showcase the experience guests are looking forward to.

## Project Overview

The goal of this redesign is to create a welcoming, visually engaging website that helps potential guests imagine their stay before they book.

Rather than simply displaying rental properties, the website highlights what makes a getaway at Lake Palo Pinto appealing: quiet mornings, fishing, time outdoors, beautiful sunsets, and the opportunity to unwind.

The design combines immersive photography, straightforward navigation, responsive layouts, and clear booking calls to action to make discovering and booking a stay easier.

## Design Direction

**Concept:** The Lake Palo Pinto Experience

The visual direction draws inspiration from the natural surroundings of the lake.

- **Deep navy:** Creates a sense of depth and contrast.
- **Lake blue:** Reflects the water and outdoor setting.
- **Warm ivory:** Keeps the experience inviting and approachable.
- **Muted sage:** Adds subtle natural tones.
- **Sun-washed gold:** Provides warmth and visual accents.

Typography pairs Cormorant Garamond for expressive headings with Inter for clean, readable body text.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project directory:

```bash
cd YOUR_PROJECT_DIRECTORY
```

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Vite will provide a local URL where you can preview the website.

### Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deployment

The website is deployed through **Vercel**, allowing the project to be built and hosted with a publicly accessible preview URL.
